# Darla Quinn — Website Concept

A cinematic editorial concept for independent singer-songwriter Darla Quinn, built around the idea of **storytelling through music**.

## Direction

- intimate, literary, musician-first visual identity
- warm paper, wine, charcoal and cream palette
- large editorial serif typography
- subtle grain, slow image movement and restrained scroll reveals
- releases treated as chapters rather than product cards
- journal content woven into the artist world

## Current build

Static HTML / CSS / JavaScript, ready for GitHub Pages.
